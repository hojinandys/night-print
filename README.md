# 밤의 지문 — 평균이 지운 자리

**밝아진 도시에서, 빛이 줄어든 곳은 어디일까?**

서울·부산·제주의 공개 야간광을 입체로 옮긴 데이터 아트입니다. 위성이 기록한 빛의 세기를 원래 위치에 높이로 세웠습니다. 멀리서는 도시의 모양을 보고, 가까이서는 그 안의 차이를 살펴봅니다.

2015–2023년 세 지역의 평균은 모두 올랐지만, 빛이 줄어든 곳도 남았습니다. **평균 그래프에 나타나지 않는 지역 내부의 차이**를 보여 주려는 작품입니다. 변화 모드에서 금빛은 증가, 푸른빛은 감소입니다. 관객은 표면을 돌리거나 지도에서 익숙한 동네를 골라 볼 수 있습니다. 빛의 변화만으로 그곳의 삶이나 변화의 원인을 판단하지는 않습니다.

두 관측 판을 구분해 감상합니다. **장기 변화**는 WorldPop / EOG의 2015–2023년 연간 관측이고, **최근 관측**은 NASA Black Marble의 2025년 10월과 2026년 10월입니다. 2026-11-23에 한국 타일에서 확인한 최신 완료 월이 2026년 10월입니다. 서로 다른 제품의 값을 하나의 시계열로 이어 붙이지 않습니다.

저장소: [hojinandys/night-print](https://github.com/hojinandys/night-print). 웹 주소: [밤의 지문](https://hojinandys.github.io/night-print/) · [최근 관측](https://hojinandys.github.io/night-print/recent/). 배포 실행 결과는 저장소 Actions에서 확인할 수 있습니다.

## 감상 순서

처음에는 **세 작품을 함께 보는 화면**으로 열립니다. 작품을 누르면 그 지역을 크게 돌릴 수 있습니다. `?region=seoul`·`?region=busan`·`?region=jeju` 또는 해당 지역 이름의 해시로 바로 들어갈 수도 있습니다. **이야기 따라보기**는 현재 고른 지역을 네 장면으로 설명하고 자유 감상으로 마칩니다. 세 지역 화면에서 시작하면 세 지역을 유지합니다. 안내가 특정 구역을 자동 선택하거나 확대하지 않습니다.

1. **관측:** 실제 지역 평균이 얼마나 변했는지 확인합니다.
2. **변화:** 같은 위치의 기준 관측값을 빼서 증가·감소한 곳을 봅니다.
3. **발견:** 평균 그래프에서 보이지 않는 변화가 표면에는 어떻게 나타나는지 찾습니다.
4. **나의 도시:** 궁금한 지역을 직접 고르고, 익숙한 동네를 살펴봅니다.

첫 화면에서는 입체를 수치보다 먼저 배치했습니다. 비교·관측 범위·정보 접기는 지역을 선택하면 나타납니다. 휴대폰에서도 연도 조작은 입체 바로 아래에 있고 지도와 상세 수치는 그 뒤에 이어집니다. 넓은 전체 화면은 기본 세로 화각을 유지해 높은 봉우리와 부속 섬이 잘리지 않도록 합니다.

안내의 수치와 방향은 지금 보는 판에서 계산합니다. 2015–2023년 장기 판에서는 세 지역 평균이 모두 올랐지만, 값이 낮아진 면적도 각각 남습니다. 부산의 9개 연도 평균은 매년 올랐어도 마지막 해에 처음보다 낮은 면적은 약 20.0%입니다. 이 근거는 해당 관측에서 확인될 때만 안내에 나오며, 최근 월간 판에 장기 판의 결론을 옮겨 쓰지 않습니다.

**두 시점 비교는 선택 기능**입니다. 지역 안에서 **비교 켜기**를 누르면 다른 실제 관측과 나란히 돌려 보고, **비교 끄기**를 누르면 B 시점의 한 작품으로 돌아갑니다. 선택한 구역과 회전 각도는 유지합니다. 안내의 마지막에도 비교를 자동으로 켜지 않습니다. 두 관측 사이의 가상 값을 만들지 않으며, 작은 화면에서는 두 작품이 위아래로 놓입니다. `세 지역` 화면에서는 한 지역을 고른 뒤 두 시점 비교와 관측 범위를 사용할 수 있습니다.

작품에는 기본적으로 **선택한 한 지점만** 표시됩니다. 지도나 구역 목록으로 장소를 고르면 경계와 정보가 함께 연결되고, `전체 지점 표시`를 켜면 작품 위에서도 모든 장소를 고를 수 있습니다. 비교 화면에서는 선택한 지점이 양쪽에 나타납니다.

작품 옆의 북쪽이 위인 지도에서 구·군·시를 선택하면 입체 화면에도 같은 경계가 표시됩니다. 경계는 원래 행정구역과 같은 좌표로 정렬하며, 관측 표면이 없는 경계 부분은 기준면의 점선으로 구분합니다. 나침반은 카메라를 돌릴 때 함께 움직입니다. 감상 모드와 전체 화면으로 안내·정보를 정리하고 작품에 집중할 수 있습니다. 전체 화면에서는 Tab으로 작품 안의 조작을 순환하며, Escape 또는 나가기 버튼으로 돌아오면 버튼에 초점이 복귀합니다. 지도를 불러오지 못하면 `지도 다시 불러오기`로 복구할 수 있습니다. 연결이 돌아왔을 때도 실패한 요청을 다시 시도합니다.

관측 범위 표시를 켜면 공통 관측에서 제외된 면적이 빗금으로 나타납니다. 유효한 관측값 0과 관측 제외는 별개입니다. 작은 차이의 범위는 ±0.1·±0.5·±1 nW/cm²/sr로 바꾸어 볼 수 있으며, 임의의 크기 기준으로 면적을 읽는 기능입니다. 통계적 오차나 유의성 기준이 아닙니다. 두 시점 비교의 수치도 선택한 두 관측과 판 전체의 고정 공통 영역에서 다시 계산한 값입니다.

연도 슬라이더와 재생 버튼으로 공개된 과거 관측을 살펴볼 수 있습니다. 다음 실제 형상을 미리 준비하고, 화면에 표시된 뒤 충분히 머물러 다음 관측으로 넘어갑니다. 로딩 중에는 현재 연도·수치·입체와 카메라를 유지하며, 연도마다 정지 이미지로 전환하지 않습니다. 자료를 불러오지 못하면 현재 장면에서 멈춰 다시 시도할 수 있습니다. 변화 모드의 기준 관측은 자기 값을 뺀 차이 0이므로 표면이 평평합니다. 선 한 줄은 한 해가 아니라 같은 표시 높이의 등고선입니다.

입체 화면은 기존 Blender 작품에 사용한 표면 좌표·시점별 높이·등고선을 그대로 내보낸 것입니다. 사진을 기울이는 방식이 아니며, 새 관측이 들어오면 회전 가능한 형상도 함께 갱신됩니다. 웹 조명과 렌더 방식은 Blender의 정지 이미지와 다르므로 광택과 그림자가 완전히 같지는 않습니다. 브라우저에서 3D를 지원하지 않거나 자료를 읽지 못하면 원래 렌더 이미지를 대체 화면으로 사용합니다.

최근 판은 지난해 같은 달의 값을 뺍니다. 이번 자료에서 서울·부산·제주의 평균은 각각 약 3.8%·11.8%·9.0% 증가했지만, 공통 관측 영역 안에서 값이 낮아진 면적도 약 40.3%·32.7%·38.6% 남습니다. 이 면적 비율은 작은 음수도 포함하며 측정 오차를 넘는 유의한 감소 비율이 아닙니다. 특히 제주의 감소는 작은 값 차이가 많습니다. 같은 달 비교로 계절 차이를 줄여도 기상·관측 품질의 영향이 없어지거나 원인이 입증되는 것은 아닙니다.

## 로컬에서 보기

저장소 폴더에서 실행합니다. 이미 포함된 웹 작품을 보는 데 데이터 다운로드나 Blender는 필요하지 않습니다.

Python 3가 설치되어 있다면 압축을 푼 뒤 macOS는 `작품_열기.command`, Windows는 `작품_열기.bat`를 실행합니다. 또는 다음 명령으로 로컬 서버와 브라우저를 함께 열 수 있습니다.

```sh
python run_preview.py
```

직접 서버만 실행하는 방법도 있습니다.

```sh
python3 -m http.server 8000 --directory dist
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. Windows에서 `python3` 대신 `python` 명령을 사용하는 환경은 그에 맞춰 실행합니다. `index.html`을 직접 여는 대신 위 주소를 사용해야 작품의 자료 파일을 정상적으로 읽습니다.

## 새로운 관측이 들어오면

`.github/workflows/update-art.yml`에는 공식 자료 확인 → 검증 → 입체 재생성 → 웹 검증 → GitHub Pages 반영 흐름을 담았습니다. GitHub 연결과 Pages 설정을 마친 뒤, `main` 변경·수동 실행·매주 월요일 12:17(KST) 일정으로 실행하도록 구성되어 있습니다.

- 새 연도가 없으면 작품은 유지하고 확인 시각만 기록합니다.
- 같은 제품의 연도가 추가되면 자료를 수집하고 세 지역을 같은 규칙으로 다시 계산합니다. 기존 이미지와 회전 가능한 표면·등고선을 모두 갱신합니다.
- 같은 판에 포함된 모든 연도의 공통 관측 영역을 사용합니다. 새 연도로 공통 영역이 달라지면 이전 연도도 그 영역에서 다시 계산합니다.
- 제품·격자 규격 변경, 연도 누락, 다운로드·렌더 검증 실패 시 기존 작품을 교체하지 않습니다. 3D 파일의 해시·배열 길이·유한값·삼각형 인덱스·관측 시점도 발행 전에 확인합니다.
- 다른 제품이나 월간 자료를 이 연간 시계열의 뒤에 그대로 붙이지 않습니다.

자동 갱신은 작품을 빠르게 움직이게 하는 장치가 아니라, 새로운 관측에도 **같은 질문과 비교 기준을 유지하는 제작 방식**입니다.

최근 판은 별도 `update-recent.yml`이 매주 화요일 12:37(KST)에 NASA의 완료된 월과 전년 동월을 확인합니다. 새 월 또는 공식 재처리 파일이 생기면 품질 검증·500m 공통 영역 집계·같은 입체 렌더·회전용 형상 검증을 거쳐 `dist/recent`만 교체합니다. 새 월에는 비교 기준도 전년 같은 달로 이동하므로, 각 판의 증감률을 같은 기준의 장기 추세로 연결하지 않습니다. 확인 시각과 관측 시각은 별도로 표시합니다.

자동 다운로드의 `EARTHDATA_TOKEN`은 저장소 **Settings → Secrets and variables → Actions**에만 저장합니다. 공개 소스에 쓰지 않습니다. 이번에 연결한 키의 만료일은 **2027-01-22**이며, 만료 전에 NASA에서 갱신하고 같은 이름의 비밀값을 교체해야 합니다. 키가 없거나 만료되면 기존 작품을 보존합니다. GitHub의 공개 저장소 정기 실행은 60일간 활동이 없으면 중지될 수 있으므로 Actions 상태를 확인합니다. 수동 실행으로도 같은 검증 절차를 시작할 수 있습니다.

NASA 자료를 직접 확인·가져오려면 다음 명령을 사용합니다. 로그인해 브라우저에서 받은 원본을 `--import-file`로 검사하는 방법도 지원합니다.

```sh
python pipeline/nasa_observations.py --check
python pipeline/nasa_observations.py --download --token-file .runtime/nasa/earthdata_token
python pipeline/build_recent.py plan
python pipeline/build_recent.py build --blender "/실제/Blender/실행파일/경로"
python pipeline/build_recent.py validate
```

원본 HDF5·다운로드 검사 기록·전체 작업 백업은 공개 제외 경로 `.runtime`에 저장합니다. HDF5 원본 파일은 대용량이므로 GitHub에 포함하지 않으며, 공개한 원본 URL과 SHA256으로 다시 검증합니다. NASA의 월간 합성값은 눈 없는 관측 중 품질 0·관측수 4회 이상을 사용합니다. 보충값·불량값·결측을 빛 0으로 바꾸지 않습니다.

작품의 결말 아래 **관측 기록**을 펼치면 보존한 판과 갱신 이력을 확인할 수 있습니다. 기록이 하나일 때는 선택 상자를 비활성화하며, 다른 판이 쌓이면 선택할 수 있습니다. 관측 기록은 실제 데이터가 추가되거나 공식 원본이 개정될 때 그 판의 수치·입체 형상·렌더·지도 자료를 고정해서 남깁니다. `data/history.json`에 기간과 변경점을, `history/`에 공개 관측 스냅샷과 파일 해시를 보존합니다. 보관한 판은 현재 감상 화면으로 다시 열 수 있습니다. 정기 확인 시각이나 UI만 바뀌면 새 관측 기록은 만들지 않습니다. 이 기능을 시작한 2026-11-23의 현재 판부터 기록하므로 처음에는 판별로 하나만 보입니다. 실제로 보존하지 않았던 과거 게시 이력을 소급해 만들지 않았습니다.

직접 자료 확인과 갱신을 실행하려면 Python 의존성과 Blender 4.4가 필요합니다.

```sh
python -m pip install -r requirements.txt
python pipeline/update.py check
python pipeline/update.py build --blender "/실제/Blender/실행파일/경로"
python pipeline/update.py validate
python -m unittest discover -s tests -v
# 지역 안내의 수치·표현 및 요청 실패 후 복구 검사 (Node.js 24)
node --test tests/*.mjs
```

`check`는 공식 연도 목록만 확인합니다. `build`는 필요한 경우에만 수집·재계산·렌더를 수행하므로 작업 시간이 길어질 수 있습니다. 작업 및 검증 이력은 `.runtime`에 기록되며, 새 판 검증을 마친 뒤에만 `dist`를 교체합니다.

## 과거 재현과 새 관측은 다릅니다

`replay`는 이미 공개된 실제 연도를 잘라 갱신 과정을 검증하는 기능입니다. 예를 들어 기존 제출본의 원자료로 2022년까지의 판을 별도로 만들 수 있습니다.

```sh
python pipeline/update.py replay --through 2022 --source-project "../night-print-regions" --blender "/실제/Blender/실행파일/경로"
```

기본 결과는 `.runtime/replay/2022`에 분리해 저장합니다. 화면과 기록에 과거 자료 재현임을 표시하며, 새로운 관측이 방금 도착한 것으로 설명하지 않습니다. 웹의 연도 재생 역시 과거 관측을 순서대로 감상하는 기능입니다.

## 자료와 읽기의 범위

- [WorldPop 공개 자료](https://hub.worldpop.org/geodata/summary?id=62620) · [DOI](https://doi.org/10.5258/SOTON/WP00772): EOG 기반 연평균 복사휘도, 단위 `nW/cm²/sr`, CC BY 4.0.
- [EOG Annual VNL](https://eogdata.mines.edu/products/vnl/): 원 야간광 제품과 방법.
- [NASA Black Marble VJ146A3 v002](https://ladsweb.modaps.eosdis.nasa.gov/missions-and-measurements/products/VJ146A3/) · [DOI](https://doi.org/10.5067/VIIRS/VJ146A3.002): NOAA-20 VIIRS, 15각초 월간 달빛·대기 보정 합성자료. 이번 최근 판은 2025-10과 2026-10의 한국 타일 h30v05를 사용합니다. 무료 Earthdata 인증이 필요합니다.
- [SGIS 경계 가공 자료](https://github.com/vuski/admdongkor/tree/master/ver20231231): 2023-12-31 고정 경계. SGIS 원자료 공공누리 제1유형, vuski/admdongkor 가공본 CC BY 4.0.
- 나눔고딕: SIL Open Font License, `dist/assets/fonts/OFL.txt` 포함.
- Three.js: MIT License, 브라우저 3D 렌더러. `dist/vendor/THREE-LICENSE.txt` 포함.

원자료를 500m 격자로 집계하고 경계 교차 면적으로 가중합니다. 100m 파일 간격을 독립적인 100m 관측 정밀도로 해석하지 않습니다. 관측이 없는 곳은 0으로 만들지 않으며, 경계 셀에는 경계 밖 값이 섞일 수 있습니다. 지역별 화면 배율은 다르고, 높이에는 공통 비선형 변환을 적용합니다.

낮아진 면적은 작은 음수까지 포함한 **값의 차이 < 0** 기준입니다. 통계적으로 유의한 감소나 도시 쇠퇴를 뜻하지 않습니다. 야간광만으로 인구·경제·관광·정책 효과 또는 변화의 원인을 단정하지 않습니다. 세 지역은 공간 형태가 다른 대비 사례이며 전국 대표 표본이 아닙니다.
